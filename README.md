# Proyecto_Seminario

Aplicación web de un autoservicio de comidas y bebidas, que permite gestionar productos como hamburguesas y bebidas.

## Funcionalidades

- Visualizar productos.
- Buscar productos por ID.
- Agregar productos.
- Modificar productos.
- Eliminar productos.

## Tecnologías

- Node.js 24.22.2
- npm 11.19.1
- Express
- JavaScript
- MySQL

## Base de datos

`tp25_autoservicio.sql`

## Ejecutar el proyecto

Instalar las dependencias:

```bash
npm install
```

Iniciar el servidor:

```bash
npm run dev
```
